⚡ 社群排程串接狀態中心

✅ 恭喜！社群一鍵串接已就緒（無須任何額外設定）
您在 Buffer 上已經成功綁定 Threads 與 Instagram 帳號。小棧後台已全面啟用「瀏覽器一鍵喚醒技術」，您不需要填寫任何 API Key、密碼或 Webhook，隨時可以直接預約發布！
🎯 平常如何將貼文送至社群排程？
1. 起草與微調：在小棧後台撰寫好貼文（可分別微調 Threads 短文與 IG 輪播版）。
2. 一鍵前往排程：點擊「⚡ 儲存並前往 Buffer 排程」或列表上的「⚡ Buffer 🧵 / 📸」。
3. 自動代入發布：系統會自動帶入專屬文案並開啟 Buffer 視窗，點一下「Add to Queue」，定時發射就完成了！
⚙️ 進階開發者設定（非必要，一般經營請直接忽略）

若您未來有架設 Make / Zapier 進行背景無介面自動推送，才需要填寫 Webhook。一般情況下保持空白即可正常使用一鍵排程。

✨ Gemini AI 協作引擎設定

將 Google Gemini API 連線至望舟後台，即可享受 真正的 AI In-The-Loop 內容協同：深度重構 Threads 鉤子短文、提煉 IG 5 頁輪播故事線與生成生圖 Prompt。

💡 如何取得 100% 免費的 Gemini API Key？
1. 前往 Google AI Studio ↗（使用一般 Google 帳號登入）。
2. 點擊「Create API key」並複製（完全免費，無須綁定信用卡）。
3. 貼到下方輸入框儲存即可！

🔑 GitHub 雲端一鍵發布設定

只需設定一次，往後在後台寫好文章或增修課程，點擊「🚀 一鍵雲端發布」即可自動更新全站，完全不需手動下載檔案或開啟 GitHub。

📌 此金鑰僅安全保存在您這台電腦的瀏覽器中，絕不會外流。
💡 如何取得 Token？（只需 1 分鐘）
1. 登入 GitHub ➔ 點右上角頭像 ➔ Settings ➔ 最下方 Developer Settings。
2. Personal access tokens ➔ Tokens (classic) ➔ Generate new token。
3. 勾選 repo 權限，點擊 Generate 複製代碼貼至上方即可。
